# Bilibili AI Subtitle Summary

A Chrome extension (Manifest V3) that grabs Bilibili video subtitles and generates an AI-powered Markdown summary with any OpenAI-compatible API.

## Features

- **Timestamped subtitles** — grabs the video's subtitle track (prefers Chinese) with timestamps
- **AI summary** — key points + timestamped outline, generated by any OpenAI-compatible API (DeepSeek by default)
- **Full transcript appended** — raw subtitle text is attached to the end of the Markdown at zero AI cost
- **Local history** — every summary is stored in IndexedDB; browse, search, and re-download anytime
- **Floating ball** — a draggable pink ball on Bilibili pages; left-click to summarize without opening the popup

## Install

1. Open `chrome://extensions` and enable **Developer mode**
2. Click **Load unpacked** and select this folder
3. Right-click the extension icon → **Options**, fill in the API Key (defaults: DeepSeek `https://api.deepseek.com/v1`, model `deepseek-chat`), then **Test connection**

## Usage

1. Open any Bilibili video page (`www.bilibili.com/video/...` or bangumi)
2. Click the extension icon → **Generate AI Summary**, or just click the pink floating ball on the page
3. The task runs in the background — no need to keep the popup open; the viewer tab opens automatically when done
4. Use popup → **History** to browse, search, delete, or re-download past summaries

## Configuration

| Setting | Description |
| --- | --- |
| API Base URL | OpenAI-compatible endpoint, e.g. `https://api.deepseek.com/v1` |
| API Key | Required for AI summaries |
| Model | Model name from your provider, e.g. `deepseek-chat` |
| Download Folder | Subfolder for `.md` files under Chrome's default download directory |
| Chunk Size (chars) | Subtitle chunk length for AI processing; long videos are split into chunks and merged |
| Temperature | AI sampling temperature (0–2) |
| Auto Open | Open the summary in a new tab when finished |

Any OpenAI Chat Completions compatible service works: DeepSeek / Kimi / Qwen / GLM / OpenAI / local Ollama — just change Base URL + Model. In mainland China, domestic services work directly; OpenAI etc. need a proxy.
